## 1. 阶段定位

本阶段将已经可用的拖放闭环完善为符合 macOS 使用习惯的完整内容架体验，补齐展示、预览、菜单、键盘、动画、多语言和设置等用户可感知能力。

## 2. 实现目标

- 提供稳定、清晰的网格和列表浏览体验。
- 补齐打开、定位、预览、移除和文本合并等日常操作。
- 使展开、收起、创建和关闭动画连续且不阻塞交互。
- 完善菜单栏、设置、日志、关于页和系统级交互。
- 完整支持英文与简体中文，并统一安全相关文案。

## 3. 范围

### 3.1 本阶段包含

- 网格/列表切换、滚动、文件图标和缩略图。
- 单选、多选、区间选择及相应键盘操作。
- 双击打开、Finder 定位、Quick Look 和链接预览。
- 右键菜单、移除、菜单合并和拖放文本合并。
- 内容架窗口与内容变化动画。
- 焦点、屏幕边缘、多显示器和深浅色模式适配。
- 菜单栏、保留天数设置、日志入口和关于页。
- 英文、简体中文、系统语言跟随、英文回退和手动切换。
- 密码、加密、安全等级和兼容性相关文案校验。

### 3.2 本阶段不包含

- 图片/视频压缩或任何媒体处理入口（产品非目标，后续阶段也不做）。
- 归档、裁剪、音频提取、ICO 转换或媒体下载入口。
- Windows 界面和跨平台适配。

## 4. 阶段交付物

- 可完成日常收集、查看、选择、预览、整理和搬运的内容架版本。
- 完整的菜单、设置、日志和关于页入口。
- 英文与简体中文 String Catalog 及术语基线。
- 核心交互、动画、多屏、无障碍和多语言验收记录。
- 文本合并、混选预览和语言回退的自动化测试。
