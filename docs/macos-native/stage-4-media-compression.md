# 阶段 4：图片与视频压缩

> 状态：待实施  
> 上级文档：[macOS 原生方案](README.md)  
> 前置阶段：[阶段 3：原生交互完善](stage-3-native-interactions.md)

## 1. 阶段定位

本阶段在完整内容架体验上加入图片和视频压缩能力，包括压缩流程自身需要的格式转换和尺寸调整。阶段范围严格限制在图片与视频，不恢复已从 PRD 中移除的处理工具。

## 2. 实现目标

- 为图片和视频提供统一、可理解的处理入口和任务状态。
- 支持 PRD 规定的质量、格式、尺寸及视频转 GIF 选项。
- 保证输出可追踪、不覆盖原文件，且单文件失败不影响其他文件。
- 支持进度、取消、错误反馈和失败重试。
- 确保外部处理能力的准备过程不阻塞内容架基本功能。

## 3. 范围

### 3.1 本阶段包含

- 图片和视频类型筛选及处理入口。
- 图片压缩、输出格式转换和尺寸调整。
- 视频压缩、输出格式转换、尺寸调整和视频转 GIF。
- 单内容架任务互斥、进度、取消、失败隔离和重试。
- 处理能力检查与首次准备流程。
- 输出命名、防覆盖和结果反馈。

### 3.2 本阶段不包含

- 文件归档与解压缩。
- 图片或视频裁剪。
- 音频提取、ICO 转换、媒体下载。
- 独立或批量的通用转换工具入口。
- 对用户原始文件的覆盖或自动删除。

## 4. 阶段交付物

- 图片和视频压缩的完整用户流程。
- 统一的处理任务状态、错误和重试体验。
- 处理能力检查及首次准备反馈。
- 媒体处理参数、输出规则和失败隔离的测试集。
- 明确证明已排除功能未进入产品入口的范围验收记录。

## 5. 验收标准

| 编号 | 验收标准 | 验收证据 |
|---|---|---|
| S4-01 | 同一内容架包含图片、视频和普通文档时，只有图片和视频参与处理，其他内容保留且不会导致任务失败。 | 混合类型验收测试 |
| S4-02 | 图片处理可按 PRD 选择质量、PNG/JPG/WebP/TIFF 输出格式和目标尺寸，输出结果可正常打开。 | 参数组合测试与样例结果 |
| S4-03 | 视频处理可按 PRD 选择质量、WebM/MP4/GIF 输出格式和目标尺寸；GIF 帧率接受 1–60，默认值为 30。 | 参数边界测试与样例结果 |
| S4-04 | 输出默认位于来源文件所在目录；存在同名文件时生成不冲突的名称，不覆盖或删除原文件。 | 文件输出与冲突测试 |
| S4-05 | 处理期间显示可理解的整体和单项状态；用户可以取消，取消后界面恢复可操作且未完成结果处理一致。 | 状态与取消验收 |
| S4-06 | 单个文件处理失败不会阻断其他文件；失败项显示可诊断原因并可单独或按任务重试。 | 失败注入与重试测试 |
| S4-07 | 同一内容架同时只运行一个处理任务，重复触发不会产生相互覆盖的任务或结果。 | 并发边界测试 |
| S4-08 | 能力缺失或首次准备失败时，内容架的收集、预览和拖放仍可正常使用，并向用户提供明确恢复路径。 | 降级场景验收 |
| S4-09 | 处理中关闭窗口、退出应用或发生外部进程异常时，不造成应用崩溃、原文件损坏或无法恢复的任务状态。 | 异常与生命周期测试 |
| S4-10 | 图片/视频处理相关界面、进度、错误和确认文案均提供英文与简体中文，语义一致且布局完整。 | 双语验收 |
| S4-11 | 产品中不存在归档、裁剪、音频提取、ICO 转换、媒体下载或独立转换工具的入口、占位提示和可达路由。 | 范围回归检查 |
| S4-12 | PRD 9.3 的全部场景通过，常用参数组合的结果质量和可播放性达到发布评审要求。 | PRD 验收记录 |

## 6. 准入条件

- 阶段 3 的所有退出条件已满足。
- 内容选择、反馈、本地化和临时文件规则稳定可复用。
- 支持的输入输出格式、外部能力及其许可证风险已有明确结论。

## 7. 退出条件

- S4-01 至 S4-12 全部通过。
- PRD 9.3 的图片与视频处理场景全部通过。
- 处理任务不会损坏、覆盖或误删用户原始文件。
- 已排除能力没有进入产品或发布范围。

## 8. PRD 映射与后续依赖

本阶段覆盖 PRD 5.6 至 5.8、7.2 的处理反馈原则及 9.3。阶段 5 将媒体处理纳入整体验收、性能、升级和发布检查，不再增加新的处理类型。
