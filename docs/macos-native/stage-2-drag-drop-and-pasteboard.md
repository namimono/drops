# 阶段 2：拖放与剪贴板主链路

> 状态：待实施  
> 上级文档：[macOS 原生方案](README.md)  
> 前置阶段：[阶段 1：内容架领域与窗口骨架](stage-1-shelf-domain-and-window.md)

## 1. 阶段定位

本阶段打通内容从外部应用进入内容架、在内容架内管理、再拖回其他应用的核心闭环，同时完成剪贴板临时内容和安全清理规则。完成后，内容架应具备基础日常使用价值。

## 2. 实现目标

- 支持文件、文件夹、链接和常见剪贴板内容进入内容架。
- 建立一致的去重、排序、选择和拖出行为。
- 完成摇动唤起与外部拖拽会话的临时内容架生命周期。
- 对剪贴板生成的临时文件实施可配置、可追踪且不误删原文件的清理规则。
- 确保拖放从触发到窗口可接收内容的链路及时、稳定且不抢焦点。

## 3. 范围

### 3.1 本阶段包含

- 文件、文件夹、URL 与剪贴板内容的识别和加入。
- 纯文本、图片、RTF、PDF 等剪贴板内容的受管落盘。
- 内容去重、前移、新内容置顶和基础选择。
- 单项、多选、范围选择和收起态整堆拖出。
- 复制、移动和取消后的内容保留规则。
- 摇动检测、拖拽会话、临时内容架晋升和关闭。
- 默认 30 天、可配置且最大 120 天的临时文件保留与安全清理。

### 3.2 本阶段不包含

- 完整网格/列表视觉、Quick Look 和高级上下文操作。
- 文本拖放合并和完整菜单合并体验。
- 图片或视频压缩。
- 外部原始文件的生命周期管理或自动删除。

## 4. 阶段交付物

- 可跨 Finder 和常用应用运行的拖入、拖出闭环。
- 剪贴板识别及受管临时文件存储能力。
- 拖拽会话与临时内容架生命周期能力。
- 临时文件元数据、保留设置、自动清理和手动清理能力。
- 拖放、去重、生命周期和文件安全相关自动化测试。

## 5. 验收标准

| 编号 | 验收标准 | 验收证据 |
|---|---|---|
| S2-01 | 可从 Finder 及至少一个第三方应用拖入文件、文件夹和链接，内容架能正确识别并展示基础类型。 | 跨应用验收记录 |
| S2-02 | 新加入内容排在最前；重复加入同一内容时不产生副本，而是将已有内容移动到最前。 | 排序与去重测试 |
| S2-03 | 分别粘贴纯文本、图片、网页链接、RTF 和 PDF 时，均形成可识别、可再次拖出的内容项。 | 剪贴板类型测试 |
| S2-04 | 单项、多选、区间选择和收起态整堆内容均可拖出；拖出顺序与内容架内顺序一致。 | 选择与拖出测试 |
| S2-05 | 拖出执行复制后内容保留，执行移动后对应内容移除，取消拖拽后内容和选择状态保持不变。 | Finder 与第三方应用验收 |
| S2-06 | 同一外部拖拽会话最多触发一个临时内容架；窗口在目标时限内可接收内容，且不抢走源应用焦点。 | 会话测试与性能记录 |
| S2-07 | 内容成功放入后临时内容架晋升为持久内容架；拖拽结束且未接收内容时自动关闭。 | 生命周期自动化测试 |
| S2-08 | 临时文件默认保留 30 天；设置仅接受正整数且最大 120 天，非法输入不覆盖上一次有效值并有明确提示。 | 设置边界测试 |
| S2-09 | 修改保留天数后，已有受管临时文件按创建时间和新配置重新计算到期时间。 | 时间规则自动化测试 |
| S2-10 | 已到期但仍被任一内容架引用的临时文件保持可用，所有活跃引用解除后才允许自动清理。 | 引用保护测试 |
| S2-11 | 手动立即清理可删除未被引用的受管临时文件，即使文件尚未到期；被引用文件被跳过并准确显示数量。 | 手动清理测试 |
| S2-12 | 自动或手动清理均不能删除拖入的原始文件、外部目录内容或通过符号链接指向受管目录外的文件。 | 路径边界与回归测试 |
| S2-13 | 多次快速拖入、拖出、取消和关闭内容架不会崩溃、丢失未移动内容或产生不可清理的孤立记录。 | 压力测试与日志检查 |

## 6. 准入条件

- 阶段 1 的所有退出条件已满足。
- 内容架生命周期、窗口标识和选择模型稳定可用。
- 受管临时目录及删除安全边界已在阶段 0 验证。

## 7. 退出条件

- S2-01 至 S2-13 全部通过。
- PRD 9.1 的基础拖放链路和 9.2 的基础粘贴场景通过。
- 临时文件保留、活跃引用保护和安全清理规则均有自动化测试。
- 核心拖入与拖出不再存在明显延迟、接收失败或焦点异常。

## 8. PRD 映射与后续依赖

本阶段覆盖 PRD 5.2“内容加入与识别”、5.4“内容选择与操作”的拖放部分、6“关键业务规则”、9.1、9.2 的粘贴部分及 9.4 的临时文件规则。阶段 3 在稳定的数据与拖放闭环上补齐完整原生交互。
