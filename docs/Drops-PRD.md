# Drops 产品需求文档（逆向梳理）

> 文档版本：V1.0  
> 对应产品版本：0.4.1  
> 梳理日期：2026-07-13  
> 文档性质：依据当前产品行为逆向整理，用于产品理解、评审与后续迭代；不描述技术实现。

## 1. 产品概述

### 1.1 产品定位

Drops 是一款桌面端临时内容收集与快捷处理工具。用户可以在不打断当前工作的情况下，快速创建一个悬浮“内容架”，把文件、文件夹、图片、文本或网页链接暂存在其中，再将这些内容批量拖往其他应用，或直接执行压缩、归档、音频提取、格式转换和媒体下载等操作。

产品的核心价值不是长期管理文件，而是在多个应用、窗口和任务之间提供一个离鼠标最近的临时中转站，减少反复切换 Finder、桌面和目标应用的成本。

### 1.2 核心价值主张

- 随时唤起：在当前鼠标位置快速出现，不要求用户先切换到 Drops。
- 临时收集：把分散在不同位置的内容汇聚为一个可整体搬运的内容包。
- 就地处理：收集后可直接完成压缩、归档、转换等常用操作。
- 多任务并行：macOS 上可同时保留多个相互独立的内容架。
- 低打扰：因拖拽临时出现但未接收内容的窗口会自动消失；主动创建的内容架由用户明确关闭。

### 1.3 目标用户

- 经常在多个应用之间搬运文件的设计师、产品经理、开发者和内容创作者。
- 需要临时汇总多份素材后再发送、上传或归档的用户。
- 经常处理图片、视频、音频和网络素材，希望减少工具切换的用户。
- 偏好键盘快捷键和拖拽操作的桌面效率用户。

### 1.4 产品目标

- 让用户在任意工作场景中，以尽可能少的操作完成内容的收集、选择和搬运。
- 将高频、轻量的文件处理能力整合到内容收集流程中。
- 保证临时内容架的创建、保留和关闭规则可预期，不干扰用户当前任务。

### 1.5 非目标

- 不作为长期文件存储、同步或网盘产品。
- 不提供复杂的文件分类、标签、搜索和版本管理。
- 不替代专业的图片、视频或音频编辑软件。
- 不承诺辅助工具覆盖所有文件格式、网站或特殊素材。

## 2. 产品范围与平台

Drops 仅面向 macOS 开发、发布和提供支持。Windows 不在产品范围内，不提供 Windows 构建、功能对齐或兼容性承诺。本文全部交互规则均以 macOS 为准。

| 能力 | macOS 规则 |
|---|---|
| 悬浮内容架 | 支持 |
| 同时创建多个内容架 | 最多同时保留 20 个 |
| 鼠标拖拽时摇动唤起 | 支持 |
| 全局快捷键唤起 | 支持自定义，在鼠标附近显示内容架 |
| 菜单栏入口 | 可创建内容架、进入设置和关于页 |
| 内容预览 | 本地内容使用系统快速预览，链接使用浏览器打开 |
| 文件快捷处理 | 具体能力取决于必要的处理组件是否就绪 |

## 3. 核心概念

### 3.1 内容架

内容架是 Drops 的核心容器，用于临时承载一组内容项。每个内容架拥有独立窗口和独立生命周期。内容架不是文件副本仓库：对于本地已有文件，主要保存其引用；对于直接粘贴或拖入的非文件内容，产品会先将其转换为可继续拖拽和处理的临时文件。

### 3.2 内容项

内容架可接收以下内容：

- 本地文件与文件夹。
- 图片、视频、音频等媒体文件。
- 网页链接。
- 剪贴板中的纯文本、图片、富文本、网页内容、PDF、表格文本、声音或通用文件内容。

同一路径在同一个内容架内不重复出现；新加入的内容排在已有内容之前。

### 3.3 临时内容与原始内容

- 本地文件或文件夹保持原位置不变。
- 剪贴板中的文本、图片等非文件内容会形成临时文件，以便预览、拖出或参与后续处理。
- 从内容架移除内容只影响内容架本身，不删除原始文件。
- 关闭内容架会清空该内容架，不删除用户原始内容。

## 4. 核心用户流程

### 4.1 快速收集并搬运内容

1. 用户通过全局快捷键、菜单栏或拖拽时摇动鼠标创建内容架。
2. 用户把一个或多个内容拖入内容架，或将剪贴板内容粘贴到内容架。
3. 内容架以堆叠形态展示内容数量，默认占用较小空间。
4. 用户可直接拖动整个内容堆，将全部内容一次性放入目标应用。
5. 如需精细操作，用户展开内容架，选择一个或多个内容，再拖往目标应用。
6. 当目标应用以“移动”方式接收内容时，对应内容从内容架移除；复制或取消拖拽时仍保留。

### 4.2 拖拽过程中临时接住内容

1. 用户在其他应用中开始拖动内容。
2. 用户快速左右/上下摇动鼠标，或按住 Shift 辅助触发。
3. 内容架在鼠标附近临时出现，且不抢占当前应用焦点。
4. 用户将内容放入该内容架后，内容架转为持久状态并继续保留。
5. 如果拖拽结束前没有放入任何内容，该临时内容架自动关闭。
6. 同一次外部拖拽最多创建一个摇动唤起的临时内容架。

### 4.3 收集后直接处理

1. 用户将待处理内容加入内容架。
2. 用户选择“压缩”“归档”或“其他工具”。
3. 系统仅允许兼容当前工具的内容参与处理，不兼容内容保留在架内但显示为不可用。
4. 用户设置输出格式、质量、尺寸等选项并开始处理。
5. 处理期间展示进度，用户可取消。
6. 处理成功后，结果替换或生成在约定位置，方便继续拖出或查看。

## 5. 功能需求

### 5.1 内容架的创建与关闭

#### 5.1.1 创建入口

- 全局快捷键：默认使用 `Command + Option + Space`，在当前鼠标位置创建内容架。
- 菜单栏“New Shelf”：在当前鼠标位置创建内容架。
- 拖拽时摇动鼠标：在拖拽进行中创建临时内容架。
- 拖拽时按住 Shift：作为更确定的辅助触发方式创建临时内容架。

#### 5.1.2 创建规则

- 通过快捷键或菜单主动创建的内容架，即使为空也保持显示，直到用户关闭。
- 通过摇动创建的内容架，只有成功接收内容后才转为持久内容架。
- macOS 最多同时存在 20 个内容架；达到上限后拒绝继续创建，并给出系统提示音。
- 每个 macOS 内容架相互独立，关闭一个不影响其他内容架。

#### 5.1.3 关闭规则

- 用户点击关闭按钮后，关闭当前内容架并清空其中的临时引用。
- 收起状态下按 Esc 不关闭内容架，避免误操作。
- 展开状态下按 Esc 只收起内容架。
- 非多内容架平台中，内容被全部移除后，窗口通常自动隐藏；用户主动唤起的空内容架继续保留。

### 5.2 内容加入与识别

#### 5.2.1 拖放加入

- 支持一次拖入一个或多个文件、文件夹或链接。
- 新加入内容显示在最前面。
- 已存在的相同内容不重复新增，但会因再次加入移动到前部。
- 拖入过程通过内容架背景状态变化提示可放置。

#### 5.2.2 粘贴加入

- 内容架获得焦点时支持系统粘贴操作。
- 本地文件直接加入内容架。
- 网页地址保留为链接内容项。
- 纯文本转换为 `.txt` 临时文件，文件名取文本开头的可读片段。
- 图片转换为图片临时文件。
- 富文本、网页、PDF、表格文本、声音和通用文件内容转换为对应临时文件。
- 同一次粘贴包含多个同名内容时，自动追加序号避免覆盖。

#### 5.2.3 内容兼容性

- 暂存模式接受所有可识别内容。
- 图片/视频压缩仅接受图片和视频文件。
- 归档接受本地文件和文件夹，不接受网页链接。
- 图标转换仅接受图片。
- 音频提取接受视频和音频文件。
- 视频下载和媒体下载仅接受网页链接。

### 5.3 内容展示

#### 5.3.1 收起态

- 默认将内容显示为一个重叠的内容堆，最多露出 3 个内容图标。
- 显示内容总数。
- 可直接拖动内容堆，一次性拖出全部内容。
- 用户可通过展开按钮或数量入口查看明细。

#### 5.3.2 展开态

- 支持网格视图和列表视图切换。
- 网格视图每行最多展示 3 个内容项。
- 图片和文件展示缩略图或文件图标；链接展示链接图标。
- 列表视图展示更完整的名称，长名称中部省略。
- 内容架支持滚动浏览超出可视区域的内容。

### 5.4 内容选择与操作

#### 5.4.1 选择规则

- 单击：只选择当前内容。
- `Command/Control + 单击`：追加选择或取消选择当前内容。
- `Shift + 单击`：按视觉顺序连续选择一个范围。
- 拖入的新内容默认加入当前选中集合。

#### 5.4.2 打开与预览

- 双击本地内容：使用系统默认应用打开。
- 双击网页链接：使用默认浏览器打开。
- 选中本地内容后按空格：调用系统快速预览；多选时按内容架顺序预览。
- 当选中内容全部为链接时，按空格打开第一个链接。

#### 5.4.3 右键菜单

- 打开：使用默认应用或浏览器打开。
- 在 Finder 中显示：定位本地文件。
- 合并文本：当已选中至少两个纯文本文件时出现。
- 移除：从内容架移除，不删除原始文件。

#### 5.4.4 拖出

- 拖动未选中的单个内容时，仅拖出该内容。
- 拖动已选中的内容时，一次拖出全部选中内容。
- 在收起态拖动内容堆时，一次拖出全部内容。
- 目标操作为移动时，成功拖出的内容从内容架移除；复制或取消时保留。

### 5.5 文本合并

文本合并用于把多段临时文本或多个 `.txt` 文件组合为一份新文本。

#### 5.5.1 菜单合并

- 用户选择至少两个 `.txt` 内容项后，可从右键菜单执行“合并文本”。
- 按内容架中的视觉顺序合并。
- 不同文本之间插入一个空行。
- 合并完成后，原选中项从内容架移除，并在其位置加入新的“合并文本”文件。
- 新文件自动成为唯一选中项。

#### 5.5.2 拖拽合并

- 展开内容架后，用户可将一个或多个已选中的纯文本项拖到另一个纯文本项上。
- 在目标上停留约半秒后进入可合并状态。
- 松开后，以目标文本为首，依次追加其他选中文本。
- 合并结果替换目标和来源项。
- 如果拖出内容架范围，则按普通文件拖出处理，不执行合并。

### 5.6 图片与视频压缩

该功能用于批量减小图片和视频体积，并可同时完成格式转换、缩放和裁剪。

#### 5.6.1 批量处理

- 可一次加入多张图片和多个视频。
- 系统先处理图片，再处理视频。
- 展示总文件数、已处理数量和当前文件进度。
- 用户可随时取消剩余处理。
- 单个文件失败时记录错误，并继续处理其他文件。
- 处理成功后，内容架中的原内容项替换为生成结果，便于直接拖出。

#### 5.6.2 图片选项

- 图片质量：最低、低、普通、高、最高、无损。
- 输出格式：与原文件相同、PNG、JPG、WebP、TIFF。
- 图片尺寸：100%、75%、50%、25%。
- 默认值：普通质量、保持原格式、保持原尺寸。

#### 5.6.3 视频选项

- 视频质量：从最低质量到最高质量，并包含无损选项。
- 输出格式：与原文件相同、WebM、MP4、GIF。
- 视频尺寸：100%、75%、50%、25%。
- 默认值：较高质量、保持原格式、保持原尺寸。

#### 5.6.4 GIF 选项

- 当输出格式选择 GIF 时，显示 GIF 专属设置。
- 可选择 GIF 质量。
- 可设置帧率，允许范围为 1–60 FPS，默认 30 FPS。
- 沿用视频尺寸缩放选项。

#### 5.6.5 输出规则

- 结果默认生成在原文件所在位置。
- 结果使用原文件名，并通过格式扩展名或自动序号避免覆盖已有文件。
- 原文件不被覆盖或删除。

### 5.7 媒体裁剪

裁剪是压缩流程中的可选前置设置，不单独立即生成文件；用户确认后，在后续压缩时应用。

#### 5.7.1 可裁剪内容

- 仅对当前选中的图片和视频开放。
- 支持批量内容逐个设置裁剪参数。
- 提供“上一项 / 下一项”和当前位置提示。

#### 5.7.2 裁剪交互

- 图片显示静态预览。
- 视频提供预览及基础播放控制，用于选择合适的画面观察裁剪效果。
- 用户分别设置左、右、上、下裁剪像素。
- 可直接输入数值，也可横向拖动字段调整。
- 实时展示原始尺寸与裁剪后尺寸。
- 限制裁剪后宽度和高度至少保留 1 像素。

#### 5.7.3 确认与取消

- 点击“Apply”保存所有已设置的裁剪参数并返回压缩页。
- 点击“Cancel”恢复打开裁剪器前的全部裁剪参数。
- 裁剪参数按每个媒体文件独立保存，仅在当前内容处理流程中使用。

### 5.8 文件归档

归档用于把选中的一个或多个文件、文件夹合并为一个压缩包。

#### 5.8.1 归档选项

- 格式：ZIP、7z、Tar 压缩包。
- 压缩级别：ZIP 和 7z 支持 0–9；0 表示不压缩，9 表示最高压缩。
- 密码：可选；输入密码后创建加密压缩包。
- 输出位置：默认与第一个来源内容相同，也可选择自定义目录。

#### 5.8.2 命名与覆盖规则

- 压缩包默认使用第一个选中内容的名称作为基础名称。
- 自动附加所选归档格式的扩展名。
- 如目标位置存在同名文件，自动生成不冲突的新名称，不覆盖原文件。

#### 5.8.3 执行反馈

- 未选择内容时不可开始归档。
- 展示归档进度。
- 允许取消正在进行的归档。
- 成功后在文件管理器中定位生成的压缩包。
- 处理失败时展示错误，并允许用户修复问题后重试。

### 5.9 其他工具（实验性）

“其他工具”统一承载较低频的转换和下载功能。当前界面明确标记为实验性，结果可能受输入内容或外部服务变化影响。

#### 5.9.1 工具自动推荐

- 拖入视频时，默认选择“提取音频”。
- 拖入图片时，默认选择“转换为 ICO”。
- 拖入音频时，默认选择“提取音频”。
- 拖入网页链接时，默认选择“媒体下载”。
- 用户可在工具下拉框中手动切换。

#### 5.9.2 提取音频

- 支持从一个或多个视频/音频文件中批量导出音频。
- 输出格式：WAV、MP3、M4A。
- 采样率：8000、16000、22050、44100、48000 Hz。
- 默认输出 WAV，采样率为 16000 Hz。
- 结果生成在原文件目录，文件名追加 `_audio`，同名时自动追加序号。
- 展示整体进度并允许取消。

#### 5.9.3 转换为 ICO

- 仅接受图片文件。
- 每次处理当前选中集合中的第一个兼容图片。
- 结果生成在原图片目录，保留基础文件名并使用 `.ico` 扩展名。
- 同名结果存在时自动生成不冲突名称。

#### 5.9.4 视频下载

- 接受一个网页链接，每次处理第一个兼容链接。
- 用于下载视频网站中的视频内容。
- 默认保存到系统“下载”目录。
- 文件名包含发布者和标题信息，并自动限制过长或不兼容字符。
- 展示下载进度；完成后打开下载目录。

#### 5.9.5 媒体下载

- 接受一个网页链接，每次处理第一个兼容链接。
- 用于下载图库、社交媒体页面等链接中的图片和视频集合。
- 默认保存到系统“下载”目录。
- 展示可获取的下载进度；完成后打开下载目录。

### 5.10 处理状态、错误与重试

- 同一内容架同一时间只执行一个处理任务。
- 任务进行中展示进度和取消入口。
- 取消后恢复为可再次操作状态，已经生成的结果不做自动删除承诺。
- 缺少必要的处理能力时，主操作按钮不可直接执行，并引导用户进入设置完成准备。
- 处理失败时展示明确错误，不让整个窗口崩溃。
- 用户可在问题处理后重试当前压缩、归档或其他工具任务。

### 5.11 首次使用与能力准备

- 首次使用高级处理功能前，引导用户完成必要能力准备。
- 展示当前检查或准备步骤和总体进度。
- 用户可取消准备、失败后重试，或根据提示手动完成准备。
- 全部准备完成后，显示成功状态并进入 Drops。
- 即使尚未完成高级处理能力准备，用户仍可使用基础内容暂存和拖放能力。

### 5.12 设置

#### 5.12.1 通用设置

- 登录时自动启动。
- 显示或隐藏菜单栏图标。
- 启用或关闭全局快捷键。
- 录制新的全局快捷键组合。
- 一键恢复默认快捷键。

#### 5.12.2 处理能力设置

- 查看各类媒体处理、下载和归档能力是否可用。
- 可自动查找所需能力，也可由用户手动指定位置。
- 未准备的能力提供安装指引。
- 用户未进行自定义时，优先使用系统可自动识别的配置。

#### 5.12.3 调试与维护

- 查看日志文件。
- 清理临时文件和缓存，执行前二次确认。
- 导出诊断信息到用户指定位置。
- 恢复全部默认设置，执行前二次确认，并提示重启后生效。

### 5.13 菜单栏与应用信息

#### 5.13.1 菜单栏

- New Shelf：创建新内容架。
- Settings：打开设置。
- About Drops：打开关于页。
- Quit：退出应用并关闭全部内容架。

- 手动检查更新，并显示检查中、发现更新或检查失败状态。

- 展示开发者信息、官网、代码仓库和社交链接。

- 展示所使用的开源组件及其许可证信息。

## 6. 关键业务规则汇总

| 编号 | 规则 |
|---|---|
| BR-01 | 新加入内容排在最前，相同路径不重复保留 |
| BR-02 | 从内容架移除或关闭内容架，不删除用户原始文件 |
| BR-03 | 主动创建的空内容架保持显示，摇动创建且未接收内容的内容架自动关闭 |
| BR-04 | 同一次外部拖拽最多产生一个摇动内容架 |
| BR-05 | macOS 同时最多存在 20 个内容架 |
| BR-06 | 收起态拖动内容堆等同于拖动全部内容 |
| BR-07 | 目标以移动方式接收时，成功拖出的内容从架内移除；复制或取消时保留 |
| BR-08 | 空格优先预览本地文件；仅选中链接时打开第一个链接 |
| BR-09 | 文本合并仅支持至少两个 `.txt` 文件，并按内容架顺序合并 |
| BR-10 | 压缩结果替换架内原内容项，但不覆盖或删除原文件 |
| BR-11 | 裁剪设置只有在后续执行压缩时才真正生成结果 |
| BR-12 | 归档以第一个选中内容命名，并避免覆盖同名结果 |
| BR-13 | 下载结果进入系统下载目录；媒体处理结果通常位于源文件目录 |
| BR-14 | 同一内容架同时只允许一个处理任务 |
| BR-15 | 不兼容当前工具的内容保留在架内，但不可参与执行 |

## 7. 状态与反馈要求

### 7.1 内容架状态

| 状态 | 用户可见表现 | 退出条件 |
|---|---|---|
| 空内容架 | 显示“放置或粘贴你的内容项” | 加入内容或用户关闭 |
| 收起态 | 显示内容堆和数量 | 用户展开、拖出全部内容或关闭 |
| 展开态 | 显示网格/列表与明细操作 | 用户收起、按 Esc 或关闭 |
| 拖入中 | 背景高亮 | 放下或移出窗口 |
| 拖出中 | 被拖内容显示半透明占位 | 完成、复制或取消拖拽 |
| 处理中 | 展示进度与取消按钮 | 成功、失败或取消 |
| 错误态 | 展示错误与修复/重试入口 | 用户处理后重试或退出 |

### 7.2 反馈原则

- 所有耗时操作必须显示进度或至少显示进行中状态。
- 可能破坏用户配置或清理数据的操作必须二次确认。
- 因输入不兼容无法执行时，应通过禁用状态和说明反馈，而不是执行后才报错。
- 错误信息应描述失败的用户操作和建议下一步，不暴露内部执行细节。

## 8. 当前产品边界与待确认项

以下内容是从当前行为逆向得到的产品边界，建议在后续产品评审中确认是否保持：

1. **结果位置不统一**：图片/视频压缩、音频提取和图标转换默认输出到源文件目录；下载输出到系统下载目录；归档界面提供自定义目录。归档自定义目录仍需作为发布验收重点，后续也建议统一成可记忆的输出策略。
2. **归档选中范围**：界面以“已选内容”为归档对象，而图片/视频压缩以架内所有兼容内容为处理对象。建议确认是否统一成“只处理选中项”。
3. **辅助工具成熟度**：音频提取、图标转换和下载功能均标记为实验性，不应在对外承诺中描述为对所有输入稳定可用。
4. **转换批量能力**：音频提取支持批量；图标转换和两类下载当前每次只处理第一个兼容内容。
5. **临时内容生命周期**：由剪贴板和文本合并产生的文件属于临时内容，当前产品没有面向用户的长期保留承诺。
6. **链接与本地内容混选预览**：只要选区中存在本地文件，空格预览优先展示本地文件，选区中的链接不会同时打开。
7. **裁剪作用时机**：裁剪器只记录参数，不会在点击“Apply”时立即输出文件，用户仍需返回压缩页执行“Compress”。
8. **加密提示**：不同运行环境下加密能力可能不同；面向用户的文案应统一表达安全等级和兼容性，避免用户误判。
9. **语言一致性**：当前界面同时存在中文和英文文案，正式发布前需确定统一语言或增加完整本地化。

此外，项目中存在未接入当前主流程、且缺少完整依赖的许可证激活页面草稿。由于用户无法从当前产品入口访问，本 PRD 不将其定义为已发布功能。

## 9. 建议的核心验收场景

### 9.1 内容架主链路

- 从任意应用拖动三个不同文件，摇动鼠标创建内容架，放入后内容架持续保留。
- 再次拖入其中一个已有文件，该文件移动到最前但不重复。
- 收起态一次拖出全部内容；复制完成后仍保留，移动完成后从架内移除。
- 展开后切换网格/列表，完成单选、多选、区间选择、预览、打开、定位和移除。

### 9.2 粘贴与文本合并

- 分别粘贴纯文本、截图和网页链接，均生成可识别、可拖出的内容项。
- 选择两份文本执行菜单合并，结果顺序与架内顺序一致且中间有空行。
- 将选中文本拖到另一文本并停留后合并；拖出窗口时不触发合并。

### 9.3 图片/视频处理

- 同一内容架中加入图片、视频和普通文档，只有图片和视频参与压缩。
- 分别验证质量、格式、尺寸以及视频转 GIF。
- 为多份媒体设置不同裁剪参数，取消时恢复原参数，应用后压缩结果符合设置。
- 处理中取消，界面恢复可操作；单文件失败不阻断其他文件。

### 9.4 归档与其他工具

- 将文件和文件夹归档为 ZIP、7z 和 Tar，验证压缩级别、密码、自定义目录和防覆盖命名。
- 批量提取音频并验证格式、采样率、命名和进度。
- 验证图片转 ICO、视频下载和媒体下载只处理第一个兼容内容。
- 必要能力未准备时，用户能获得明确引导并在修复后重试。

### 9.5 多内容架与系统入口

- 通过快捷键连续创建多个内容架，各自内容和关闭行为互不影响。
- 拖拽未落入时，摇动创建的临时内容架自动关闭；成功落入时保留。
- 达到 20 个内容架后无法继续创建并获得反馈。
- 菜单栏可创建内容架、打开设置、打开关于页和退出应用。

## 10. 产品成功指标建议

当前项目未内置明确的业务指标定义。若进入正式产品迭代，建议关注：

- 内容架创建后成功接收内容的比例。
- 每个内容架平均承载内容数。
- 内容架从创建到首次拖出的耗时。
- 整体拖出、多选拖出和快捷处理的使用占比。
- 各处理功能的成功率、取消率和失败原因分布。
- 摇动唤起后的误触关闭率。
- 日活跃用户的人均内容架创建次数和跨应用拖放次数。
