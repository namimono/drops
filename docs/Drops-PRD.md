## 1. 产品概述

### 1.1 产品定位

Drops 是一款 macOS 临时内容收集与快捷处理工具。用户可以在不打断当前工作的情况下，快速创建一个悬浮“内容架”，把文件、文件夹、图片、文本或网页链接暂存在其中，再将这些内容批量拖往其他应用，或直接压缩图片和视频。

产品的核心价值不是长期管理文件，而是在多个应用、窗口和任务之间提供一个离鼠标最近的临时中转站，减少反复切换 Finder、桌面和目标应用的成本。

### 1.2 核心价值主张

- 随时唤起：在当前鼠标位置快速出现，不要求用户先切换到 Drops。
- 临时收集：把分散在不同位置的内容汇聚为一个可整体搬运的内容包。
- 就地处理：收集后可直接完成图片和视频压缩、格式转换与缩放。
- 多任务并行：macOS 上可同时保留多个相互独立的内容架。
- 低打扰：因拖拽临时出现但未接收内容的窗口会自动消失；主动创建的内容架由用户明确关闭。

### 1.3 目标用户

- 经常在多个应用之间搬运文件的设计师、产品经理、开发者和内容创作者。
- 需要临时汇总多份素材后再发送、上传或整理的用户。
- 经常处理图片和视频素材，希望减少工具切换的用户。
- 偏好键盘快捷键和拖拽操作的桌面效率用户。

### 1.4 产品目标

- 让用户在任意工作场景中，以尽可能少的操作完成内容的收集、选择和搬运。
- 将高频、轻量的文件处理能力整合到内容收集流程中。
- 保证临时内容架的创建、保留和关闭规则可预期，不干扰用户当前任务。

### 1.5 非目标

- 不作为长期文件存储、同步或网盘产品。
- 不提供复杂的文件分类、标签、搜索和版本管理。
- 不替代专业的图片、视频或音频编辑软件。
- 不提供文件归档、媒体裁剪、音频提取、ICO 转换或网络媒体下载能力。

## 2. 产品范围与平台

Drops 仅面向 macOS 开发、发布和提供支持。Windows 不在产品范围内，不提供 Windows 构建、功能对齐或兼容性承诺。本文全部交互规则均以 macOS 为准。

| 能力 | macOS 规则 |
|---|---|
| 悬浮内容架 | 支持 |
| 同时创建多个内容架 | 最多同时保留 20 个 |
| 鼠标拖拽时摇动唤起 | 支持 |
| 全局快捷键唤起 | 支持自定义，在鼠标附近显示内容架 |
| 菜单栏入口 | 可创建内容架、进入设置和关于页 |
| 内容预览 | 本地内容使用系统快速预览，链接使用浏览器打开 |
| 文件快捷处理 | 支持图片和视频压缩、格式转换与缩放；具体能力取决于必要的处理组件是否就绪 |

## 3. 核心概念

### 3.1 内容架

内容架是 Drops 的核心容器，用于临时承载一组内容项。每个内容架拥有独立窗口和独立生命周期。内容架不是文件副本仓库：对于本地已有文件，主要保存其引用；对于直接粘贴或拖入的非文件内容，产品会先将其转换为可继续拖拽和处理的临时文件。

### 3.2 内容项

内容架可接收以下内容：

- 本地文件与文件夹。
- 图片、视频、音频等媒体文件。
- 网页链接。
- 剪贴板中的纯文本、图片、富文本、网页内容、PDF、表格文本、声音或通用文件内容。

同一路径在同一个内容架内不重复出现；新加入的内容排在已有内容之前。

### 3.3 临时内容与原始内容

- 本地文件或文件夹保持原位置不变。
- 剪贴板中的文本、图片等非文件内容会形成临时文件，以便预览、拖出或参与后续处理。
- 从内容架移除内容只影响内容架本身，不删除原始文件。
- 关闭内容架会清空该内容架，不删除用户原始内容。
- 应用管理的临时文件默认保留 30 天，用户可以在设置中修改为不超过 120 天的正整数天数。
- 保留期从临时文件创建时间开始计算；修改设置后，已有临时文件按新的保留天数重新计算到期时间。
- 应用启动时以及运行期间每日检查一次到期临时文件。
- 到期但仍被当前内容架引用的临时文件暂不删除；从所有内容架移除或内容架关闭后再清理。
- 自动清理和手动清理都只能删除由 Drops 创建并纳入管理的临时文件，不得删除用户原始文件。
- 用户手动执行“立即清理”时，可以清理尚未到期但已不被任何内容架引用的受管临时文件；仍被引用的文件必须跳过并反馈数量。

## 4. 核心用户流程

### 4.1 快速收集并搬运内容

1. 用户通过全局快捷键、菜单栏或拖拽时摇动鼠标创建内容架。
2. 用户把一个或多个内容拖入内容架，或将剪贴板内容粘贴到内容架。
3. 内容架以堆叠形态展示内容数量，默认占用较小空间。
4. 用户可直接拖动整个内容堆，将全部内容一次性放入目标应用。
5. 如需精细操作，用户展开内容架，选择一个或多个内容，再拖往目标应用。
6. 当目标应用以“移动”方式接收内容时，对应内容从内容架移除；复制或取消拖拽时仍保留。

### 4.2 拖拽过程中临时接住内容

1. 用户在其他应用中开始拖动内容。
2. 用户快速左右/上下摇动鼠标，或按住 Shift 辅助触发。
3. 内容架在鼠标附近临时出现，且不抢占当前应用焦点。
4. 用户将内容放入该内容架后，内容架转为持久状态并继续保留。
5. 如果拖拽结束前没有放入任何内容，该临时内容架自动关闭。
6. 同一次外部拖拽最多创建一个摇动唤起的临时内容架。

### 4.3 收集后直接处理

1. 用户将待处理内容加入内容架。
2. 用户进入图片/视频压缩功能。
3. 系统仅允许图片和视频参与处理，不兼容内容保留在架内但显示为不可用。
4. 用户设置输出格式、质量、尺寸等选项并开始处理。
5. 处理期间展示进度，用户可取消。
6. 处理成功后，结果替换或生成在约定位置，方便继续拖出或查看。

## 5. 功能需求

### 5.1 内容架的创建与关闭

#### 5.1.1 创建入口

- 全局快捷键：默认使用 `Command + Option + Space`，在当前鼠标位置创建内容架。
- 菜单栏“New Shelf”：在当前鼠标位置创建内容架。
- 拖拽时摇动鼠标：在拖拽进行中创建临时内容架。
- 拖拽时按住 Shift：作为更确定的辅助触发方式创建临时内容架。

#### 5.1.2 创建规则

- 通过快捷键或菜单主动创建的内容架，即使为空也保持显示，直到用户关闭。
- 通过摇动创建的内容架，只有成功接收内容后才转为持久内容架。
- macOS 最多同时存在 20 个内容架；达到上限后拒绝继续创建，并给出系统提示音。
- 每个 macOS 内容架相互独立，关闭一个不影响其他内容架。

#### 5.1.3 关闭规则

- 用户点击关闭按钮后，关闭当前内容架并清空其中的临时引用。
- 收起状态下按 Esc 不关闭内容架，避免误操作。
- 展开状态下按 Esc 只收起内容架。
- 内容被全部移除后，用户主动创建的内容架继续保留，直到用户明确关闭。

### 5.2 内容加入与识别

#### 5.2.1 拖放加入

- 支持一次拖入一个或多个文件、文件夹或链接。
- 新加入内容显示在最前面。
- 已存在的相同内容不重复新增，但会因再次加入移动到前部。
- 拖入过程通过内容架背景状态变化提示可放置。

#### 5.2.2 粘贴加入

- 内容架获得焦点时支持系统粘贴操作。
- 本地文件直接加入内容架。
- 网页地址保留为链接内容项。
- 纯文本转换为 `.txt` 临时文件，文件名取文本开头的可读片段。
- 图片转换为图片临时文件。
- 富文本、网页、PDF、表格文本、声音和通用文件内容转换为对应临时文件。
- 同一次粘贴包含多个同名内容时，自动追加序号避免覆盖。

#### 5.2.3 内容兼容性

- 暂存模式接受所有可识别内容。
- 图片/视频压缩仅接受图片和视频文件。

### 5.3 内容展示

#### 5.3.1 收起态

- 默认将内容显示为一个重叠的内容堆，最多露出 3 个内容图标。
- 显示内容总数。
- 可直接拖动内容堆，一次性拖出全部内容。
- 用户可通过展开按钮或数量入口查看明细。

#### 5.3.2 展开态

- 支持网格视图和列表视图切换。
- 网格视图每行最多展示 3 个内容项。
- 图片和文件展示缩略图或文件图标；链接展示链接图标。
- 列表视图展示更完整的名称，长名称中部省略。
- 内容架支持滚动浏览超出可视区域的内容。

### 5.4 内容选择与操作

#### 5.4.1 选择规则

- 单击：只选择当前内容。
- `Command/Control + 单击`：追加选择或取消选择当前内容。
- `Shift + 单击`：按视觉顺序连续选择一个范围。
- 拖入 / 粘贴的新内容成为唯一选中项（不再并入旧选区）。

#### 5.4.2 打开与预览

- 双击本地内容：使用系统默认应用打开。
- 双击网页链接：使用默认浏览器打开。
- 选中本地内容后按空格：调用系统快速预览；多选时按内容架顺序预览。
- 同时选中本地内容和链接时，按空格只快速预览本地内容，不同时打开链接。
- 当选中内容全部为链接时，按空格打开第一个链接。

#### 5.4.3 右键菜单

- 打开：使用默认应用或浏览器打开。
- 在 Finder 中显示：定位本地文件。
- 合并文本：当已选中至少两个纯文本文件时出现。
- 移除：从内容架移除，不删除原始文件。

#### 5.4.4 拖出

- 拖动未选中的单个内容时，仅拖出该内容。
- 拖动已选中的内容时，一次拖出全部选中内容。
- 在收起态拖动内容堆时，一次拖出全部内容。
- 目标操作为移动时，成功拖出的内容从内容架移除；复制或取消时保留。

### 5.5 文本合并

文本合并用于把多段临时文本或多个 `.txt` 文件组合为一份新文本。

#### 5.5.1 菜单合并

- 用户选择至少两个 `.txt` 内容项后，可从右键菜单执行“合并文本”。
- 按内容架中的视觉顺序合并。
- 不同文本之间插入一个空行。
- 合并完成后，原选中项从内容架移除，并在其位置加入新的“合并文本”文件。
- 新文件自动成为唯一选中项。

#### 5.5.2 拖拽合并

- 展开内容架后，用户可将一个或多个已选中的纯文本项拖到另一个纯文本项上。
- 在目标上停留约半秒后进入可合并状态。
- 松开后，以目标文本为首，依次追加其他选中文本。
- 合并结果替换目标和来源项。
- 如果拖出内容架范围，则按普通文件拖出处理，不执行合并。

### 5.6 图片与视频压缩

该功能用于批量减小图片和视频体积，并可同时完成格式转换和缩放。

#### 5.6.1 批量处理

- 可一次加入多张图片和多个视频。
- 系统先处理图片，再处理视频。
- 展示总文件数、已处理数量和当前文件进度。
- 用户可随时取消剩余处理。
- 单个文件失败时记录错误，并继续处理其他文件。
- 处理成功后，内容架中的原内容项替换为生成结果，便于直接拖出。

#### 5.6.2 图片选项

- 图片质量：最低、低、普通、高、最高、无损。
- 输出格式：与原文件相同、PNG、JPG、WebP、TIFF。
- 图片尺寸：100%、75%、50%、25%。
- 默认值：普通质量、保持原格式、保持原尺寸。

#### 5.6.3 视频选项

- 视频质量：从最低质量到最高质量，并包含无损选项。
- 输出格式：与原文件相同、WebM、MP4、GIF。
- 视频尺寸：100%、75%、50%、25%。
- 默认值：较高质量、保持原格式、保持原尺寸。

#### 5.6.4 GIF 选项

- 当输出格式选择 GIF 时，显示 GIF 专属设置。
- 可选择 GIF 质量。
- 可设置帧率，允许范围为 1–60 FPS，默认 30 FPS。
- 沿用视频尺寸缩放选项。

#### 5.6.5 输出规则

- 结果默认生成在原文件所在位置。
- 结果使用原文件名，并通过格式扩展名或自动序号避免覆盖已有文件。
- 原文件不被覆盖或删除。

### 5.7 处理状态、错误与重试

- 同一内容架同一时间只执行一个处理任务。
- 任务进行中展示进度和取消入口。
- 取消后恢复为可再次操作状态，已经生成的结果不做自动删除承诺。
- 缺少必要的处理能力时，主操作按钮不可直接执行，并引导用户进入设置完成准备。
- 处理失败时展示明确错误，不让整个窗口崩溃。
- 用户可在问题处理后重试当前压缩任务。

### 5.8 首次使用与能力准备

- 首次使用高级处理功能前，引导用户完成必要能力准备。
- 展示当前检查或准备步骤和总体进度。
- 用户可取消准备、失败后重试，或根据提示手动完成准备。
- 全部准备完成后，显示成功状态并进入 Drops。
- 即使尚未完成高级处理能力准备，用户仍可使用基础内容暂存和拖放能力。

### 5.9 设置

#### 5.9.1 通用设置

- 登录时自动启动。
- 显示或隐藏菜单栏图标。
- 启用或关闭全局快捷键。
- 录制新的全局快捷键组合。
- 一键恢复默认快捷键。
- 设置临时文件保留天数；默认 30 天，只接受不超过 120 的正整数。
- 切换界面语言；首版默认支持英文和简体中文。

#### 5.9.2 处理能力设置

- 查看图片和视频压缩所需处理能力是否可用。
- 可自动查找所需能力，也可由用户手动指定位置。
- 未准备的能力提供安装指引。
- 用户未进行自定义时，优先使用系统可自动识别的配置。

#### 5.9.3 调试与维护

- 查看日志文件。
- 清理临时文件和缓存，执行前二次确认；仍被内容架引用的临时文件必须跳过并反馈数量。
- 导出诊断信息到用户指定位置。
- 恢复全部默认设置，执行前二次确认，并提示重启后生效。

#### 5.9.4 语言与安全文案

- 首版提供英文和简体中文两套完整界面文案。
- 默认跟随 macOS 系统语言；系统语言不受支持时使用英文。
- 用户可在设置中明确选择英文或简体中文，并覆盖跟随系统的结果。
- 面向用户的密码、加密或安全相关文案必须准确表达安全等级、适用范围和兼容性，避免使用可能造成安全能力误判的笼统描述。

### 5.10 菜单栏与应用信息

#### 5.10.1 菜单栏

- New Shelf：创建新内容架。
- Settings：打开设置。
- About Drops：打开关于页。
- Quit：退出应用并关闭全部内容架。

#### 5.10.2 关于页

- 展示产品名称和当前版本。
- 手动检查更新，并显示检查中、发现更新或检查失败状态。
- macOS 每日自动在后台检查一次更新。
- 展示开发者信息、官网、代码仓库和社交链接。
- 支持打开日志目录。
- 展示所使用的开源组件及其许可证信息。

## 7. 状态与反馈要求

### 7.1 内容架状态

| 状态 | 用户可见表现 | 退出条件 |
|---|---|---|
| 空内容架 | 显示“放置或粘贴你的内容项” | 加入内容或用户关闭 |
| 收起态 | 显示内容堆和数量 | 用户展开、拖出全部内容或关闭 |
| 展开态 | 显示网格/列表与明细操作 | 用户收起、按 Esc 或关闭 |
| 拖入中 | 背景高亮 | 放下或移出窗口 |
| 拖出中 | 被拖内容显示半透明占位 | 完成、复制或取消拖拽 |
| 处理中 | 展示进度与取消按钮 | 成功、失败或取消 |
| 错误态 | 展示错误与修复/重试入口 | 用户处理后重试或退出 |

### 7.2 反馈原则

- 所有耗时操作必须显示进度或至少显示进行中状态。
- 可能破坏用户配置或清理数据的操作必须二次确认。
- 因输入不兼容无法执行时，应通过禁用状态和说明反馈，而不是执行后才报错。
- 错误信息应描述失败的用户操作和建议下一步，不暴露内部执行细节。

## 8. 当前产品边界与已确认决策

以下决策已经确认，并作为后续设计、开发和验收的正式边界：

1. **归档能力**：不进入产品范围，不设计、不开发、不验收文件归档及其格式、密码、输出目录等衍生能力。
2. **辅助工具**：不提供音频提取、ICO 转换、视频下载和媒体下载，不保留“其他工具”入口。
3. **独立转换能力**：不提供辅助工具中的单项或批量转换入口；图片/视频压缩功能自身包含的输出格式转换仍保留。
4. **媒体裁剪**：不进入产品范围，不在图片/视频压缩流程中提供裁剪设置。
5. **临时内容生命周期**：所有由 Drops 创建并管理的临时文件默认保留 30 天，用户可以配置保留天数，但最大不得超过 120 天。到期但仍被内容架引用的文件在引用解除后清理；任何清理都不得删除用户原始文件。
6. **链接与本地内容混选预览**：只要选区中存在本地文件，按空格就只预览本地文件；只有选区全部为链接时才打开第一个链接。
7. **安全文案**：面向用户的密码、加密或安全相关文案必须统一、准确地表达安全等级、适用范围和兼容性，避免用户误判。当前版本不因该文案要求新增归档或其他加密功能。
8. **语言支持**：首版完整支持英文和简体中文，默认跟随 macOS 系统语言，不支持的系统语言回退为英文；用户可以在设置中手动切换。

此外，项目中存在未接入当前主流程、且缺少完整依赖的许可证激活页面草稿。由于用户无法从当前产品入口访问，本 PRD 不将其定义为已发布功能。

## 9. 建议的核心验收场景

### 9.1 内容架主链路

- 从任意应用拖动三个不同文件，摇动鼠标创建内容架，放入后内容架持续保留。
- 再次拖入其中一个已有文件，该文件移动到最前但不重复。
- 收起态一次拖出全部内容；复制完成后仍保留，移动完成后从架内移除。
- 展开后切换网格/列表，完成单选、多选、区间选择、预览、打开、定位和移除。

### 9.2 粘贴与文本合并

- 分别粘贴纯文本、截图和网页链接，均生成可识别、可拖出的内容项。
- 选择两份文本执行菜单合并，结果顺序与架内顺序一致且中间有空行。
- 将选中文本拖到另一文本并停留后合并；拖出窗口时不触发合并。

### 9.3 图片/视频处理

- 同一内容架中加入图片、视频和普通文档，只有图片和视频参与压缩。
- 分别验证质量、格式、尺寸以及视频转 GIF。
- 处理中取消，界面恢复可操作；单文件失败不阻断其他文件。

### 9.4 临时文件、语言与安全文案

- 未修改设置时，新建临时文件的保留期为 30 天。
- 将保留期调整到 120 天可以保存；超过 120 天的输入不能生效并获得明确提示。
- 修改保留期后，已有临时文件按创建时间和新配置重新计算到期时间。
- 到期但仍在内容架中的临时文件保持可用，从所有内容架移除后才能清理。
- 自动清理和手动清理都不会删除拖入的原始文件或文件夹。
- 手动立即清理会删除未被引用的受管临时文件，即使尚未到期；仍被引用的文件会被跳过并显示数量。
- 分别在英文和简体中文环境验证全部核心页面、菜单、错误和确认文案；不支持的系统语言使用英文。
- 所有密码、加密或安全相关文案均明确说明安全等级、适用范围和兼容性，不暗示产品具备未实现的加密能力。

### 9.5 多内容架与系统入口

- 通过快捷键连续创建多个内容架，各自内容和关闭行为互不影响。
- 拖拽未落入时，摇动创建的临时内容架自动关闭；成功落入时保留。
- 达到 20 个内容架后无法继续创建并获得反馈。
- 菜单栏可创建内容架、打开设置、打开关于页和退出应用。

## 10. 产品成功指标建议

当前项目未内置明确的业务指标定义。若进入正式产品迭代，建议关注：

- 内容架创建后成功接收内容的比例。
- 每个内容架平均承载内容数。
- 内容架从创建到首次拖出的耗时。
- 整体拖出、多选拖出和快捷处理的使用占比。
- 图片/视频压缩的成功率、取消率和失败原因分布。
- 摇动唤起后的误触关闭率。
- 日活跃用户的人均内容架创建次数和跨应用拖放次数。
